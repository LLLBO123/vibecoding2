# 家庭点菜小程序 v0.1 范围

目标：最低成本家庭内测版。

```text
不正式上线
不备案
不买服务器
不用域名
不用 FastAPI
只用微信小程序体验版 + 微信云开发免费额度
```

## v0.1 只做 4 件事

```text
1. 今日菜单
2. 家人点菜
3. 自动汇总买菜清单
4. 所有人能同步看到
```

## 先不做

```text
邀请码
订阅提醒
复杂登录
多家庭
支付
后台管理
```

## 成员怎么处理

固定 9 个成员：

```text
爸爸
妈妈
奶奶
廖宇鹏
大姐
二姐
老弟
陈茵
其他人
```

进入小程序后，第一次在“家人”页选择“我是谁”，保存到本机。

这样暂时不用微信登录和权限系统。

## 数据怎么存

用微信云开发数据库，5 个集合：

```text
fm_settings
fm_votes
fm_menus
fm_shopping
fm_history
```

含义：

```text
fm_settings：家庭固定配置，包含成员名单、菜品库
fm_votes：每天谁点了什么菜
fm_menus：每天最终确认的菜单
fm_shopping：每天自动生成的买菜清单
fm_history：每天确认菜单的历史记录
```

所有数据都用同一个固定家庭 ID：

```text
family-default
```

这样不做多家庭、不做邀请码，先让一家人用起来。

## 家人怎么用

在微信开发者工具里：

```text
上传体验版
```

然后到微信公众平台：

```text
成员管理 -> 体验成员
```

把家人微信号加进去。

家人扫体验二维码就能用。
