# 家庭点菜小程序 v0.1 体验版配置

目标：不用上线、不用备案，只用微信小程序体验版 + 云开发，让家人同步点菜、确认菜单、查看买菜清单。

## 3. 创建云数据库集合

在云开发控制台的数据库里创建 5 个集合：

```text
fm_settings
fm_votes
fm_menus
fm_shopping
fm_history
```

它们分别存：

- `fm_settings`：固定家庭成员、客家菜品库、默认时间设置
- `fm_votes`：每天每个成员点了哪些菜
- `fm_menus`：每天最终确认的菜单
- `fm_shopping`：每天的买菜清单和已买状态
- `fm_history`：每天确认过的菜单历史，后续用于避免重复和反馈

## 4. 设置数据库权限

体验版要让家人共同编辑同一份菜单和买菜清单，所以 5 个集合都要用自定义规则。

每个集合都设置成自定义安全规则：

```json
{
  "read": true,
  "write": true
}
```

这个规则只适合家庭体验版。以后如果要正式上线，需要改成只允许家庭成员读写。

不要选“所有用户可读、创建者可读写”。那个规则会导致一个人创建的菜单，其他家人可能无法修改。

## 5. 初始化数据

配置好集合后，重新编译小程序。

第一次打开时，小程序会自动往 `fm_settings` 写入：

- 爸爸、妈妈、奶奶、廖宇鹏、大姐、二姐、老弟、陈茵、其他人
- 100 道客家菜和常见广东家常菜
- 7:30 点菜提醒、8:30 确认菜单、8-9 点买菜窗口
