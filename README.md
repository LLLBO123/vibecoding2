# 今天吃什么 - 家庭点菜小程序 v0.1

这是一个最低成本家庭内测版：微信小程序体验版 + 微信云开发免费额度。

## 当前已做

- 家人切换：爸爸、妈妈、奶奶、廖宇鹏、大姐、二姐、老弟、陈茵、其他人
- 每日点菜：家人可以点想吃的菜，再次点击取消
- 投票汇总：首页按票数展示大家想吃什么
- 家人定菜单：所有成员都可以从投票结果里勾选今天要做的菜
- 买菜清单：根据菜单自动合并食材，并支持勾选已买
- 示例菜品库：内置 100 道常规家庭菜，广东家常 60 道、客家菜 40 道，按 10 个大类均衡整理
- 点菜节奏：7:30 提醒点菜，8:30 建议确认菜单，8-9 点买菜
- 云开发同步：填入云环境 ID 后，点菜、菜单、买菜清单会同步到云数据库
- 一键清空：可以清空当前成员今日点菜，也可以清空今日菜单
- 分享菜单：今日菜单页可分享给家人
- 随机搭配：按人数随机生成菜单组合
- 同步状态：菜单和采购保存会提示已同步，失败会提醒重试
- 采购优化：常见数量合并、固定分类顺序、已买沉底、可隐藏已买
- 刷新入口：今日、菜库、确认、采购支持手动刷新和下拉刷新
- 今日参与：显示已点和未点成员
- 历史记录：确认菜单时写入轻量历史数据

## v0.1 范围

只做：

- 今日菜单
- 家人点菜
- 自动汇总买菜清单
- 所有人能同步看到
- 菜库搜索
- 菜单/采购分享
- 同步状态提示
- 采购清单优化
- 手动刷新/下拉刷新
- 今日参与情况
- 轻量历史菜单

先不做：

- 邀请码
- 订阅提醒
- 复杂登录
- 多家庭
- 支付
- 后台管理

## 产品定位

v0.1 不做“家庭版外卖点餐”，只做家庭吃饭协商工具：

- 家人轻松表达想吃什么
- 做饭的人轻松确认今天做什么
- 买菜的人清楚知道要买什么

详细说明见 [v0.1 范围](docs/v0.1-scope.md)。

## 如何打开

1. 安装微信开发者工具
2. 选择“导入项目”
3. 项目目录选择当前文件夹
4. 当前项目已填好 AppID 和云开发环境 ID
5. 要给家人体验，按 `docs/experience-cloud-dev.md` 创建云数据库集合并上传体验版
6. 编译后从“家人”页切换成员测试点菜
